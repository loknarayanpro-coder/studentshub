## 🚀 Features
- **Syllabus & Units Explorer:** Unit 1–5 topics, course outcomes, and direct links.
- **Notes Vault:** High-yield handwritten faculty notes and toppers' formula sheets with in-browser PDF viewer.
- **Question Paper Archive:** Official Anna University Nov/Dec and Apr/May semester question papers.
- **Important Questions Bank:** Repeating 2-mark and 13/15-mark Part C questions from actual AU exams.
- **Student Productivity Tools:**
  - Regulation 2021 GPA Calculator (pre-configured for Sem 5 CSE courses)
  - 75% Attendance Rule & Medical Condonation Safe-Bunk Calculator
  - Academic Calendar & Exam Countdown
- **Placement & Internships:** 2026/2027 batch tech internships and core CS interview prep (OS, Networks, DBMS, System Design, DSA).

---

## 🛠️ Technology Stack
- **Framework:** Next.js 16 (Turbopack, App Router)
- **Language:** TypeScript
- **Styling:** Vanilla Tailwind CSS with custom Midnight Navy + Electric Lime design system
- **Icons:** Lucide React
- **Database:** Supabase PostgreSQL with RLS policies
- **Storage:** AWS S3 presigned URLs for secure PDF delivery
